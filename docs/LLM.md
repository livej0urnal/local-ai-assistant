# Локальная модель R2-D2

## Роли в приложении

```text
Пользователь
    ↓
C-3PO — интерфейс, голос, подтверждения
    ↓
R2-D2 — локальная LLM, анализ и текстовый ответ
    ↓
Rust — проверка и выполнение только разрешённых действий
```

R2-D2 не получает прямого доступа к shell, файлам или системным API. Ответ модели является текстом,
а не командой для немедленного выполнения.

## Текущая конфигурация разработчика

- движок: `llama-server` из llama.cpp;
- сервер-маршрутизатор слушает только `127.0.0.1:11436`;
- базовая модель: `Qwen2.5-1.5B-Instruct`, квантизация `Q4_K_M`;
- формат: GGUF v3;
- контекст прототипа: 4096 токенов;
- ускорение macOS: Metal, все слои модели выгружаются на GPU;
- модель занимает около 1,35 ГБ объединённой памяти при запуске;
- файл модели не хранится в Git и находится в системной папке данных приложения.

Релизный установщик содержит статически собранный `llama-server`. Панель моделей предлагает одну
явную кнопку загрузки трёх официальных Qwen GGUF Q4_K_M: общий пакет занимает около 5,7 ГБ. Файлы
скачиваются напрямую с Hugging Face, сначала сохраняются с расширением `.part`, проходят проверку
размера и сигнатуры `GGUF` и только затем становятся доступными приложению. Повторный запуск
пропускает уже установленные корректные модели.

Qwen2.5 выбрана для первого прототипа из-за поддержки нескольких языков и совместимости с уже
установленным `llama-server`. Это небольшая тестовая модель; качество рассуждений можно повысить
переходом на 3B/7B после проверки всего конвейера.

## Маршрутизация моделей

`llama-server` запускается с `--models-dir`, `--models-max 1` и автоматической загрузкой. В памяти
одновременно находится не более одной модели. Имя файла определяет специализацию:

- `*Coder*.gguf` — задачи программирования;
- `Qwen3*` или `*creative*.gguf` — тексты и анализ почты;
- остальные корректные GGUF — общие вопросы.

В интерфейсе роли получили имена дроидов:

| Дроид | Реальная модель | Назначение |
|---|---|---|
| R2-D2 | Qwen2.5 1.5B Q4_K_M | общение и быстрые команды |
| BB-8 | Qwen2.5-Coder 3B Q4_K_M | Rust, PHP, TypeScript и поиск ошибок |
| K-2SO | Qwen3 4B Q4_K_M | тексты, документы и анализ почты |

Переключатель хранится локально. В ручном режиме Rust принимает только точное имя уже найденного
GGUF-файла; произвольный путь из интерфейса передать нельзя. В режиме «Автовыбор» действует
классификация задачи по роли.

Перед отправкой запрос классифицируется локально по назначению. Если специализированной модели нет,
используется базовая общая. HTTP-запрос ограничен 90 секундами, а запуск сервера — 30 секундами.

Интерфейс и язык команд настраиваются независимо. Сейчас доступны русский, английский, испанский,
немецкий, французский, итальянский, португальский, упрощённый китайский, японский и арабский.
Выбранный язык передаётся в защищённую системную инструкцию из фиксированного списка.

## Память о собеседниках

Для запоминания имени не требуется переобучать GGUF-модель. C-3PO хранит локальные профили,
отдельные диалоги и до 100 последних сообщений в каждом диалоге, а имя текущего собеседника передаёт
модели как контекст. Команда «Другой пользователь» начинает новое знакомство. Ответы вроде «да» или
«хочу» проверяются и не сохраняются как имена. Автоматическое
распознавание человека по голосу пока не используется: голосовой отпечаток является биометрией и
потребует отдельного явного согласия, локальной модели speaker recognition и возможности удалить
сохранённый отпечаток.

## Запуск

Панель локальной модели открывается кнопкой `R2-D2` в верхней части интерфейса. Она показывает:

1. найден ли движок llama.cpp;
2. найдена ли корректная GGUF-модель;
3. состояние локального сервера;
4. PID и текущий RSS процесса R2-D2;
5. результат тестового вопроса.

Кнопка «Запустить модель» создаёт отдельный процесс `llama-server`. Обычный крестик оставляет его
работать в фоне. Пункт «Завершить C-3PO» в строке меню или кнопка «Остановить» завершает процесс.

## Безопасность

- запуск выполняется через отдельные аргументы `Command`, без shell-строки;
- путь выбирается только из проверенной папки моделей;
- файл должен иметь расширение `.gguf` и сигнатуру `GGUF`;
- сервер привязан к loopback-адресу и недоступен из локальной сети;
- длина одного запроса ограничена 4000 символами;
- системный промпт запрещает модели заявлять о выполнении компьютерных действий;
- фактические действия в следующих этапах будут проходить отдельную проверку Rust.

## Звуки R2-D2

Текущие сигналы процедурно синтезируются через Web Audio API и не являются аудиофрагментами из
фильмов. Во время запроса анимированный R2-D2 появляется прямо в текущем диалоге напротив аватара
C-3PO: мигает глаз, движется голограмма и отображается их короткий технический обмен. После ответа
временная реплика исчезает, а C-3PO передаёт полный ответ локальному Chatterbox TTS и произносит его
с разрешённым приватным образцом. Готовые реакции используются только для коротких системных событий.
