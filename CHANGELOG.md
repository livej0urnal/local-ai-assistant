# Журнал изменений

Все заметные изменения C-3PO Local Assistant описываются в этом файле. Версии следуют
[Semantic Versioning](https://semver.org/).

## [1.0.1] — 2026-11-11

- исправлена проверка Windows в релизном CI: платформенная компиляция и тесты выполняются отдельно,
  а строгий Clippy остаётся на нативных macOS runners;
- функциональность приложения соответствует стабильной линии 1.0.

## [1.0.0] — 2026-11-11

Первый стабильный настольный выпуск для macOS и Windows.

### Основные возможности

- голосовой и текстовый интерфейс с локальным фоновым пробуждением на macOS;
- локальные модели R2-D2, BB-8, K-2SO и BD-1 через встроенный `llama-server`;
- безопасный запуск приложений, поиск и анализ файлов, проектов и кода;
- текущая погода, анализ экрана, Apple Mail и Calendar;
- диалоги, профили пользователей, темы, 10 языков и беззвучный режим;
- отложенные задачи с прогрессом, уведомлениями и подтверждением изменяющих действий;
- системная диагностика, журнал ошибок и мониторинг памяти процесса;
- обратимые операции с файлами, кодовыми патчами, черновиками и событиями.

### Надёжность и безопасность

- единый экземпляр приложения и завершение устаревших дочерних процессов при запуске;
- локальное Apple Speech без сетевого fallback для пакетной macOS-сборки;
- исправлена конкуренция нативного и Web Speech слушателей в свёрнутом режиме;
- расширено распознавание произношений имени C-3PO;
- модель не получает shell-доступ, а аргументы системных действий проверяются Rust;
- удаление, отправка и необратимые действия требуют подтверждения;
- кроссплатформенная сборка DMG/NSIS и публикация SHA-256 через GitHub Actions.
