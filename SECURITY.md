# Безопасность

## Поддерживаемые версии

Проект находится на стадии раннего прототипа. Исправления безопасности применяются только к
актуальной ветке разработки.

## Модель безопасности

- интерфейс Vue не запускает shell-команды;
- Rust экспортирует только явно зарегистрированные Tauri-команды;
- неизвестные действия должны отклоняться;
- запись и удаление данных будут требовать подтверждения;
- файловые операции будут ограничены разрешёнными пользователем папками;
- модель не считается доверенным источником команд;
- приложения запускаются только по идентификатору из фиксированного каталога, без shell-строк;
- внешняя отправка Telegram требует отдельного подтверждения с показом контакта и текста;
- приложение использует ограничительную Content Security Policy.
- внутренние аудио и каталог доступны только с origin самого приложения; интернет для них не нужен;
- микрофон активируется только после системного разрешения пользователя;
- активный голосовой режим всегда отображается на главном экране и может быть поставлен на паузу;
- права на файлы, экран и управление не запрашиваются до появления использующей их функции.
- сервер llama.cpp слушает только `127.0.0.1:11436`, имеет общий тайм-аут запроса и завершается
  вместе с приложением;
- сервер полного синтеза речи слушает только `127.0.0.1:11438`, ограничивает размер и язык запроса
  и не записывает произносимый текст в журнал;
- закрытие окна скрывает приложение, но пункт «Завершить C-3PO» в строке меню останавливает процесс.
- фоновый ответ отправляется только через официальный модуль уведомлений Tauri после системного
  разрешения пользователя; текст уведомления ограничен 500 символами.
- Telegram-автоматизация передаёт контакт и сообщение в AppleScript отдельными аргументами, а журнал
  сохраняет только длины полей; прежнее содержимое буфера обмена восстанавливается.

## Текущие ограничения

Распознавание речи в прототипе использует возможности WebView и может зависеть от системных или
облачных служб платформы. Не используйте голосовой ввод для конфиденциальной информации до
подключения и проверки локального whisper.cpp.

Приложение пока не имеет подписанных публичных сборок. Не устанавливайте двоичные файлы из
неофициальных источников.

Приватные голосовые MP3, эталон TTS и модели GGUF не входят в публичный репозиторий. Перед передачей
сборки убедитесь, что лицензия разрешает распространение каждого вложенного аудио- и модельного
файла. Подключайте только собственный голос или запись с явным разрешением на синтетическую речь.

## Сообщение об уязвимости

До настройки отдельного приватного канала не публикуйте эксплуатационные детали в открытом issue.
Свяжитесь с владельцем репозитория через профиль GitHub и укажите, что сообщение относится к
безопасности C-3PO Local Assistant.
