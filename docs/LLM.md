# Локальная модель R2-D2

## Роли в приложении

```text
Пользователь
    ↓
C-3PO — интерфейс, голос, подтверждения
    ↓
R2-D2 — локальная LLM, анализ и текстовый ответ
    ↓
Rust — проверка и выполнение только разрешённых действий
```

R2-D2 не получает прямого доступа к shell, файлам или системным API. Ответ модели является текстом,
а не командой для немедленного выполнения.

## Текущая конфигурация разработчика

- движок: `llama-server` из llama.cpp;
- сервер слушает только `127.0.0.1:11435`;
- модель: `Qwen2.5-1.5B-Instruct`, квантизация `Q4_K_M`;
- формат: GGUF v3;
- контекст прототипа: 4096 токенов;
- ускорение macOS: Metal, все слои модели выгружаются на GPU;
- модель занимает около 1,35 ГБ объединённой памяти при запуске;
- файл модели не хранится в Git и находится в системной папке данных приложения.

Qwen2.5 выбрана для первого прототипа из-за поддержки русского языка и совместимости с уже
установленным `llama-server`. Это небольшая тестовая модель; качество рассуждений можно повысить
переходом на 3B/7B после проверки всего конвейера.

## Запуск

Панель локальной модели открывается кнопкой `R2-D2` в верхней части интерфейса. Она показывает:

1. найден ли движок llama.cpp;
2. найдена ли корректная GGUF-модель;
3. состояние локального сервера;
4. PID и текущий RSS процесса R2-D2;
5. результат тестового вопроса.

Кнопка «Запустить модель» создаёт отдельный процесс `llama-server`. При закрытии приложения или
нажатии «Остановить» дочерний процесс завершается.

## Безопасность

- запуск выполняется через отдельные аргументы `Command`, без shell-строки;
- путь выбирается только из проверенной папки моделей;
- файл должен иметь расширение `.gguf` и сигнатуру `GGUF`;
- сервер привязан к loopback-адресу и недоступен из локальной сети;
- длина одного запроса ограничена 4000 символами;
- системный промпт запрещает модели заявлять о выполнении компьютерных действий;
- фактические действия в следующих этапах будут проходить отдельную проверку Rust.

## Звуки R2-D2

Текущие сигналы процедурно синтезируются через Web Audio API и не являются аудиофрагментами из
фильмов. R2-D2 подаёт сигнал о начале анализа, успехе, ошибке или остановке, после чего C-3PO
озвучивает текстовый перевод. Лицензированный звуковой пакет можно будет подключить через тот же
слой, не меняя LLM.
