# Безопасность

## Поддерживаемые версии

Исправления безопасности выпускаются для последней опубликованной версии и актуальной ветки
`master`. Перед сообщением о проблеме проверьте её на последнем релизе.

## Модель безопасности

- интерфейс Vue не запускает shell-команды;
- Rust экспортирует только явно зарегистрированные Tauri-команды;
- неизвестные действия должны отклоняться;
- запись, отправка и удаление данных требуют подтверждения;
- файловые операции ограничены домашней или явно выбранной пользователем папкой;
- модель не считается доверенным источником команд;
- приложения запускаются только после поиска установленного пакета в системном каталоге, без
  составления shell-строк;
- внешняя отправка Telegram требует отдельного подтверждения с показом контакта и текста;
- приложение использует ограничительную Content Security Policy.
- внутренние аудио и каталог доступны только с origin самого приложения; интернет для них не нужен;
- микрофон активируется только после системного разрешения пользователя;
- активный голосовой режим всегда отображается на главном экране и может быть поставлен на паузу;
- C-3PO может открыть системные настройки разрешений, но не может выдать разрешение себе;
- сервер llama.cpp слушает только `127.0.0.1:11436`, имеет общий тайм-аут запроса и завершается
  вместе с приложением;
- сервер полного синтеза речи слушает только `127.0.0.1:11438`, ограничивает размер и язык запроса
  и не записывает произносимый текст в журнал;
- закрытие окна скрывает приложение, но пункт «Завершить C-3PO» в строке меню останавливает процесс.
- фоновый ответ отправляется только через официальный модуль уведомлений Tauri после системного
  разрешения пользователя; текст уведомления ограничен 500 символами.
- Telegram-автоматизация передаёт контакт и сообщение в AppleScript отдельными аргументами, а журнал
  сохраняет только длины полей; прежнее содержимое буфера обмена восстанавливается.
- отдельный журнал действий фиксирует тип, уровень риска, решение и результат, но не сохраняет текст
  сообщений, поисковых запросов или введённых команд.
- письма и календарные события читаются через разрешённые Apple Events, а не напрямую из баз данных;
  содержимое считается недоверенным и не может отдавать системные команды модели;
- создание письма ограничено видимым черновиком; автоматическая отправка и удаление писем отсутствуют.

## Безопасный анализ файлов

C-3PO не запрашивает постоянный полный доступ к диску. Для анализа пользователь самостоятельно
выбирает файлы или папку, видит их список в диалоге и может отменить выбор. Поддерживаются только
текстовые форматы, не более 10 файлов и 1 МБ на файл; в локальную модель передаётся ограниченный
фрагмент. Функция работает только на чтение и не умеет изменять или удалять выбранные данные.

## Границы доверия

Пакетная macOS-сборка использует Apple Speech только при доступном on-device распознавании и не
переходит на сетевой режим. Windows использует возможности системного WebView, поведение которых
зависит от установленного речевого компонента ОС. Для конфиденциальных команд на Windows используйте
текстовый режим, если локальность системного распознавания не подтверждена настройками ОС.

Публичные сборки без сертификатов Apple и Microsoft могут показывать системное предупреждение.
Устанавливайте файлы только со страницы GitHub Releases и сверяйте `SHA256SUMS.txt`.

Встроенные короткие MP3 записаны автором и входят в публичный репозиторий. Эталон для полного TTS,
его веса и модели GGUF не входят в релиз. Перед добавлением нового аудио убедитесь, что лицензия
разрешает его распространение и синтетическую речь. Подключайте только собственный голос или запись
с явным разрешением владельца.

## Сообщение об уязвимости

До настройки отдельного приватного канала не публикуйте эксплуатационные детали в открытом issue.
Свяжитесь с владельцем репозитория через профиль GitHub и укажите, что сообщение относится к
безопасности C-3PO Local Assistant.
