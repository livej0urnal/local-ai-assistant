# Участие в разработке

Спасибо за интерес к C-3PO Local Assistant.

## Подготовка

1. Сделайте fork репозитория.
2. Создайте ветку от актуальной основной ветки.
3. Установите зависимости командой `npm install`.
4. Запустите приложение через `npm run tauri dev`.

## Перед pull request

```bash
npm run build
cargo fmt --check --manifest-path src-tauri/Cargo.toml
cargo test --manifest-path src-tauri/Cargo.toml
```

Добавляйте тесты для новой логики Rust. Изменения системных разрешений, файловых операций и
выполнения команд должны отдельно описывать последствия для безопасности.

## Правила проекта

- не добавляйте выполнение произвольных shell-строк;
- не передавайте личные данные во внешние сервисы без явного согласия;
- не добавляйте модели и другие крупные двоичные файлы непосредственно в Git;
- не коммитьте содержимое `public/private-audio`: в Git хранится только инструкция;
- не используйте клонированные голоса реальных людей;
- проверяйте сценарии «закрыть окно», «открыть из строки меню» и «полностью завершить»;
- сохраняйте тайм-ауты для локальных моделей: интерфейс не должен бесконечно оставаться в ожидании;
- сохраняйте работу на macOS и Windows;
- поддерживайте документацию вместе с изменениями функциональности.
