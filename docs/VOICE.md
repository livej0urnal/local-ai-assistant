# Локальная озвучка C-3PO

## Что работает сейчас

C-3PO произносит полный новый ответ, сформированный локальной LLM, через Chatterbox Multilingual.
Голосовой образец `voice.mp3` записан самим автором проекта. Это не запись актёра и не извлечённая
дорожка фильма. Образец, созданные из него фразы и веса моделей не публикуются в GitHub.

```text
Вопрос → llama.cpp формирует полезный текст → Chatterbox клонирует разрешённый тембр
       → локальный WAV → динамики
```

85 ранее подготовленных фрагментов сохраняются только для коротких событий: приветствия при
запуске, предупреждения и завершения. Они больше не заменяют содержательный ответ модели.

При запуске C-3PO заранее поднимает голосовой процесс и загружает веса Chatterbox с диска. Новый
ответ делится по предложениям и словам на фрагменты примерно до 110 символов. Первый фрагмент
начинает воспроизводиться сразу после генерации, а следующий синтезируется параллельно с текущим
звуком. Это уменьшает задержку до первого слова; общее время вычисления всё ещё зависит от длины
ответа и мощности компьютера.

## Установка для другого пользователя

Нужен Python 3.11 и собственная либо лицензированная чистая запись речи:

```bash
python3.11 scripts/setup-local-voice.py --voice /absolute/path/to/reference.wav
```

На Windows:

```powershell
py -3.11 scripts/setup-local-voice.py --voice C:\Users\Name\voice.wav
```

Скрипт устанавливает зафиксированную версию `chatterbox-tts==0.1.7` в изолированное окружение
папки данных C-3PO. Поддерживаются WAV, MP3, M4A, FLAC и OGG. Рекомендуется 8–15 секунд одного
голоса без музыки, эха и фонового шума. Публичная сборка полностью работает без этого компонента,
но тогда произвольные ответы остаются текстом.

## Приватность и безопасность

- HTTP-сервис слушает только `127.0.0.1:11438` и недоступен из локальной сети;
- текст и голосовой образец не отправляются внешнему TTS-сервису;
- первый запуск скачивает публичные веса модели, дальнейшая генерация локальна;
- журнал хранит длину текста и ошибки, но не сам текст и не аудиозапись;
- один запрос ограничен 1200 символами и языками из фиксированного списка;
- процесс завершается вместе с полным завершением C-3PO;
- на платформах без нативного Perth-модуля используется предоставленный библиотекой fallback,
  потому что иначе текущая версия падает во время загрузки.

## Права на голос

Подключайте только собственную запись либо материал с явным разрешением на синтетическую
озвучку. Владение отдельным аудиофайлом не всегда означает право клонировать голос другого
человека. Голоса актёров, дорожки фильмов, интервью и другие чужие записи нельзя включать без
подходящей лицензии. Права на голос также не дают прав на персонажей и товарные знаки.

## Диагностика

Основной журнал: системная папка данных C-3PO, `logs/c3po.log`.
Журнал голосового процесса: там же `logs/tts-server.log`. Состояние компонента видно в настройках.
Если синтез недоступен, точный ответ всё равно остаётся в диалоге и не подменяется случайной фразой.
