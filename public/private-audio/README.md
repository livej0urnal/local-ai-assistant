# Локальные голосовые материалы

Эта папка предназначена для коротких личных голосовых реакций разработчика. Все файлы, кроме этого
README, игнорируются Git и не публикуются в репозитории. Полные новые ответы озвучивает Chatterbox;
его установка и правила описаны в `docs/VOICE.md`.

Каталог создаётся командой:

```bash
node scripts/build-private-voice-catalog.mjs <source.mp3> <whisper.json>
```

Скрипт создаёт `catalog.json` и отдельные MP3-фрагменты, размеченные по ситуациям: `startup`,
`introduction`, `waiting`, `success`, `warning`, `error` и `shutdown`. Приложение сначала произносит
стартовую фразу, затем включает микрофон, чтобы не распознать собственный голос как команду.

В production CSP должны оставаться `connect-src 'self'`, локальный адрес TTS и `media-src 'self'
blob:`, иначе встроенный каталог и сгенерированное аудио будут заблокированы WebView.

Перед распространением записи необходимо отдельно подтвердить права на голос и исходные фрагменты.
