# Руководство пользователя C-3PO

## Установка

Скачайте установщик для своей системы со страницы
[последнего релиза](https://github.com/livej0urnal/local-ai-assistant/releases/latest):

- macOS Apple Silicon — `.dmg` с `aarch64` в имени;
- macOS Intel — `.dmg` с `x64` или `x86_64`;
- Windows 10/11 x64 — `setup.exe`.

Сборки пока не подписаны. Система может показать предупреждение о неизвестном разработчике. Не
отключайте системную защиту целиком: разрешайте запуск только файла, скачанного из официального
репозитория проекта.

Для проверки загрузки откройте терминал в папке с установщиком и `SHA256SUMS.txt`:

```bash
# macOS
shasum -a 256 -c SHA256SUMS.txt

# Windows PowerShell — сравните результат со строкой файла SHA256SUMS.txt
Get-FileHash .\имя-установщика.exe -Algorithm SHA256
```

## Первый запуск

1. Откройте C-3PO и нажмите «Настроить доступы» в мастере первого запуска.
2. Последовательно подтвердите системные окна микрофона, уведомлений, Почты и Календаря.
3. На macOS мастер откроет «Универсальный доступ»: включите C-3PO, вернитесь в приложение и нажмите
   «Проверить готовность». Выданное состояние сохраняется и без причины повторно не запрашивается.
4. В настройках выберите микрофон, тему и режим голоса. Беззвучный режим оставляет только чат.
5. Откройте панель моделей. Установщик уже содержит `llama-server`, но GGUF-модели загружаются
   отдельно и только после нажатия «Установить 3 модели».

Доступ к файлам выдаётся при выборе конкретной папки. Анализ экрана не запрашивается, пока нет
функции, которой он действительно нужен.

В панели моделей можно выбрать R2-D2, BB-8 или K-2SO, а также удалить ненужный файл. Перед удалением
C-3PO показывает имя и размер модели и просит подтверждение.

## Основные команды

- «Покажи информацию о системе» — ОС, архитектура, память компьютера и C-3PO;
- «Открой Google Chrome», «Открой калькулятор» — запуск установленного приложения;
- «Открой Chrome и найди документацию Rust» — безопасный поиск в браузере;
- «Найди файл README.md» — локальный поиск файлов и папок по имени без открытия Finder;
- «Открой заметки и напиши Купить молоко» — сразу введёт текст без его отправки;
- «Напиши в Telegram контакту Любимая сообщение Я скоро буду» — покажет адресата и полный текст,
  затем потребует отдельное подтверждение отправки;
- «Какая сейчас погода?» — получает сводку в фоне, не открывая приложение «Погода».
- «Проанализируй почту и расставь приоритеты» — локально группирует последние письма Apple Mail;
- «Проанализируй календарь и мою загруженность на неделю» — показывает нагрузку и свободные окна;
- «Напиши письмо на user@example.com тема Встреча текст Добрый день» — создаёт обратимый черновик,
  но не отправляет его;
- «Составь письмо для user@example.com тема Встреча о том, что нужно перенести её на пятницу» —
  локальная K-2SO подготовит текст и покажет его перед созданием черновика;
- «Создай событие Планирование завтра с 10:00 до 11:00» — добавляет обратимое событие;
- «Отмени последнее действие» — удаляет последний созданный C-3PO черновик или событие.

Когда окно скрыто, голосовая команда должна начинаться с имени: «C-3PO, …». Если сказать только
имя, откроется главное окно. Любая новая речь прерывает текущий голосовой ответ. При открытом чате
ответы выводятся текстом без озвучки.

## Диалоги и данные

История, профили, настройки и модели хранятся на этом компьютере. В панели диалога можно создать
новый разговор, переключаться между разговорами и удалить один разговор или всю историю.
Удаление подтверждается внутри интерфейса C-3PO; очищенный список сохраняется пустым и больше не
восстанавливается из истории старой версии приложения.

Обычный журнал не сохраняет аудио и текст голосовых команд. Отдельный журнал действий содержит
тип действия, риск, результат и технические размеры данных, но не текст сообщений и поиска. Пути к
обоим файлам показаны в окне «Доступы».

## Если что-то не работает

- микрофон: проверьте выбранное устройство и системное разрешение, затем полностью перезапустите
  C-3PO;
- приложение не найдено: произнесите точное имя, под которым оно показано в Finder или меню Пуск;
- локальная модель долго запускается: для слабого компьютера выберите меньшую модель и закройте
  другие программы, использующие много памяти;
- голос запаздывает: выберите режим «Быстрый»; режим личного голоса требует больше ресурсов;
- подробности ошибки: откройте «Доступы» → «Журнал событий и ошибок».

Полностью завершить фоновое приложение можно через пункт «Завершить C-3PO» в меню значка C-3PO.
